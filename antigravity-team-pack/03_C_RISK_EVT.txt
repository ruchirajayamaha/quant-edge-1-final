C2 - UNCONDITIONAL POT-GPD EVT
Fit losses above threshold u: excess=loss-u conditional on loss>u, scipy.stats.genpareto.fit(excess, floc=0). State location, scale and support conventions. Core is unconditional EVT, with dependence/volatility limitations disclosed.

Threshold grid: configurable90/92.5/95percentiles is a starting set, not an automatic justification. Produce mean residual life, shape xi and threshold-adjusted scale beta(u)-xi*u, exceedance counts, tail QQ/PP diagnostics and sensitivity of final risk estimates. Raw beta need not be constant across thresholds. Record the diagnostic rationale for a proposed threshold; team review remains pending. Do not claim an automatic rule passed a fitted-GPD Anderson-Darling test unless calibrated correctly.

For n observations and N_u strict exceedances, define a=(n/N_u)*(1-c):
VaR_c = u + beta/xi * (a**(-xi)-1).
For xi near0 use the stable exponential limit VaR_c=u-beta*log(a).
ES_c = (VaR_c+beta-xi*u)/(1-xi), only for xi<1.

Require a<1 for extrapolation above u, sufficient exceedances, positive beta, valid support and finite fit. If xi>=1, ES is not finite; diagnose it instead of exporting a plausible number. Reject requests below the fitted tail domain. For example, a95%threshold cannot estimate90%EVT VaR; show unavailable rather than extrapolating downwards or silently changing the selected threshold.

A default500-day window yields only about25exceedances at95%, incompatible with minimum50. Request a separate sufficient EVT window, e.g.1260observations with actual counts checked. For any conventional-versus-EVT dashboard comparison use that same larger window for all compared methods, or clearly separate different-window sensitivity results. No hidden window mismatch. A's selected primary-model backtest may still use its own documented500-day rolling window.

Provide modest configurable block-bootstrap uncertainty for dependent financial losses, with reproducible seed, explicit block-length assumption and failed-fit counts. Cache it; report it as conditional on the threshold choice. A cheap iid parametric interval may additionally illustrate fit-only uncertainty if labelled; it does not account for volatility clustering or threshold-selection uncertainty. Never run bootstrap during every app rerun.

Tests: xi near0, xi>=1ES unavailable, bounded negative-xi support, too few exceedances, requested quantile below threshold, deterministic known-parameter quantiles, and seeded GPD parameter recovery with sensible statistical tolerance. Small isolated formula checks are more useful than a huge fragile simulation suite.
